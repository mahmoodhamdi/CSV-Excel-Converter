Last updated: 2026-05-13

The converter ships under three commercial models. Pick the one that matches how you'd rather pay: once, monthly, or by API call.

### What "Vertical" means

Each vertical comes pre-configured with:

- Brand identity (logo, color palette, copy in English + Arabic)
- Domain-specific templates (e.g., QuickBooks → Xero mapping for AccountingBridge)
- Format compliance options (ETA e-invoice JSON, ZATCA XML for InvoiceFlow)
- Pricing/landing pages tuned for the industry
- Sample data for the vertical

The 5 verticals available today:

| Vertical | Audience | Hero Feature |
|---|---|---|
| AccountingBridge | Accountants in MENA | Windows-1256 auto-decode + ETA e-invoice export |
| EduGrades | Schools and tutors | Egyptian GPA ↔ international scale + Moodle import |
| DevDataKit | Engineering teams | API-first, schema inference, all SDKs |
| CRMSync | Sales operations | HubSpot/Salesforce/Zoho field mappers + dedup |
| InvoiceFlow | E-invoicing | ETA (Egypt) + ZATCA (Saudi) compliance |
